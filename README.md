# Depression Prediction from Social Media Text

## Overview

**Depression Prediction from Social Media Text** is a **group machine learning project** that explores how machine learning and Transformer-based language models can be used to identify patterns in social media text that may be associated with signs of depression.

The project combines embeddings generated using **BERT, RoBERTa, and DistilBERT** with an **XGBoost meta-classifier** to make predictions from textual input. A **Streamlit-based web application** provides an interactive interface for testing the trained model.

> **Group Project:** This project was developed collaboratively as part of a team. Other members of the same group may have uploaded their own copy of this project to their individual GitHub profiles. These repositories represent the **same group project**, not separate or independent projects.

## Project Objectives

* Explore Transformer-based models for text representation.
* Generate meaningful embeddings from social media text.
* Combine embeddings from multiple Transformer models.
* Use XGBoost as a meta-classifier for prediction.
* Build an interactive Streamlit application for real-time testing.

## How It Works

### 1. Text Preprocessing

The input text is cleaned and prepared for processing before being passed to the Transformer models.

### 2. Embedding Extraction

Each text input is processed using three Transformer-based models:

* **BERT**
* **RoBERTa**
* **DistilBERT**

The resulting representations are extracted and used as numerical features.

### 3. Feature Combination

The embeddings generated by the three models are combined to create a richer representation of the input text.

### 4. XGBoost Classification

The combined embeddings are passed to an **XGBoost meta-classifier**, which predicts whether the given text contains patterns associated with depression.

### 5. Streamlit Application

The trained model is integrated into a **Streamlit web application**, allowing users to enter text and receive a prediction through an interactive interface.

## Installation

Clone the repository and navigate to the project directory:

```bash
git clone https://github.com/ishabhosale04/Depression-Prediction-Using-ML.git
cd Depression-Prediction-Using-ML
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser. Enter social media text into the input field to see the model's prediction.

## Dataset

The project uses `sentiment.csv` as the dataset for training and testing the machine learning model.

The quality and diversity of the dataset can have a significant impact on model performance. Social media language can be highly varied, and individual posts may not always provide enough context for reliable classification.

## Disclaimer

This project is intended **for educational and research purposes only**.

The model's prediction should **not be treated as a medical diagnosis or professional mental health assessment**. Depression is a complex condition that cannot be reliably determined from a person's text alone.

Model performance depends on factors such as the dataset, training process, language patterns, and the context available in the input text.
